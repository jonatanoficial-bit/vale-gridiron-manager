# Registro de direitos

Esta pasta é reservada a documentos e manifestos referentes a ativos usados na distribuição. O Lote 02 inclui o registro dos escudos em [`TEAM-LOGOS-2026.md`](TEAM-LOGOS-2026.md), com estado de direitos explicitamente pendente de documentação comprobatória no repositório.

Cada asset futuro deve registrar, no mínimo: identificador, tipo, sujeito, temporada, URL/fonte, licença declarada, escopo permitido, evidência e checksum.
